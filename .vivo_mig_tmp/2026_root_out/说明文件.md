## 5 格式规范

- 自包含单文件 HTML ：CSS 与 SVG 全部内联，无 CDN / 外链，离线可开，浏览器直接打开。
- 暗色卡片风格 ：背景 #0d1117、卡片 #161b22、品牌色蓝 #58a6ff / 紫 #bc8cff / 绿 #3fb950 / 红 #ff7b72。
- 图表为内联 SVG ：步数柱状图按值着色（达标绿 / 未达标蓝 / 久坐黄 / 缺失灰），虚线为 8000 目标线。
- 正文首行 为高亮周期标注条（周报 / 月总结各自的规范格式，见 3.3 / 3.4）。
- 命名固定： 第X周.html 、 月度总结.html ；标题与首行一一对应。

## 6 数据口径与准确性

- 步数 / 距离 / 热量的日度数据由导出包内嵌的 2 小时粒度 JSON 还原，与导出包「步数」列逐行比对 842/842 天完全吻合（误差 0） 。
- 220 份周报的「总步数」累加 = 4,309,299 步，与日度数据总和 分毫不差 （每日恰好被一周且仅一周覆盖）。
- 静息心率 = 睡眠期第 5 百分位 （非"日最低"标量），全期基线 55 bpm。
- 中高强度分钟 = 心率 ≥119 bpm 的 时间加权 时长（采样间隔中位 5 秒）。
- 夜间心率下降率 =（清醒均 − 睡眠均）/ 清醒均；\<10% 计为 non-dipping。
- 个体基线：静息心率 55 bpm、主睡眠得分中位 79——建议模块的低/高判断以此为参照。
- 心率原始明细 49 万采样点取自 vivo 服务器外链；\<40 bpm 的 91 个点（0.019%）为佩戴松动伪迹，已说明不影响统计。
