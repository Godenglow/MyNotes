## 第七轮:伪表格剔除(用户截图 4 张 + "表格是给人类看的吗")

**用户反馈 5 张截图:**
1. "什么是关键字" → 表格里"Java关键字是 Java 编程语言..."被断成多列
2. if/else 分支代码 → `if( 布尔表达式 ){` 被拍成"表格"
3. IDEA 快捷键 → 8+ 列多列拆 prose
4. 汽车类/银行账户 → `定义一个汽车类,...` 同上被拆
5. 所有"碎成多列的 PPT 排版"

**根因:**
- PPTX 里"段落 + tab 分隔" + 多个 textbox 拼成一行 → 我误认为真表格
- 但实际 PPT 一行内常常是 prose 描述 + 几个文本碎片(tab 隔开)

**修复:**
- `looks_like_table` 加 4 重过滤:
  1. 行数 ≥ 3 才算表
  2. 短行(≤ 30 chars) + 中文字符多 → 不算表
  3. 列数 ≤ 3 行数 ≤ 5 + 任意 cell > 25 chars → 不算表
  4. 列数不稳定(max-min ≥ 3)+ 中文多 → 不算表
- 表格里的 junk cell(1 chars)过滤更严
- 短行不再粘合(避免 `'02 关键字' + 'Java 关键字有哪些' + 'Java关键字 都是小写的'` 被粘成一坨)
- 加最后兜底:全局 tab → 空格替换(不破坏代码块)
- 修了**死循环 bug**(tab_run 空时只 `continue` 而不 `i += 1`)
- FOOTER_RE 简化:`\d{1,3}[\t\s]\S.{0,18}$` 匹配更宽的页脚形式
