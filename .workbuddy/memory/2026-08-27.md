## 语雀笔记抓取(MySQL 笔记)
- **任务**: 把 https://www.yuque.com/dujubin/ltckqu/qxzqmq 复制到 D:\MyNotes\MySQL.md
- **结果**: 成功,5.09 万字 / 6328 行,40 个 H1,79 个 H2,83 个 H3,约 315 个代码块

### 关键方法(下次可复用)
- **WebFetch 失效原因**: 语雀是 SPA,正文通过 `/api/docs/{slug}` 异步加载,直接抓 HTML 只能拿到 meta 和侧栏目录,正文 `body`/`body_asl` 在 API JSON 里是空字符串。
- **正确做法**: curl 调用 `https://www.yuque.com/api/docs/{slug}?book_id={bookId}&mode=markdown`,返回的 `data.sourcecode` 字段就是完整的 Markdown 源(约 175 KB)。
- **book_id 怎么拿**: 直接 `curl` 网页 HTML,搜 `book_id` 数值(本次是 31872399);也可以从语雀侧栏目录脚本里提取。
- **绕过路径陷阱**: Windows bash 不能直接写 `/d/MyNotes/foo.md`,先 `cd /d/MyNotes && python3 ... open('foo.md', 'w')` 才稳。
- **不要重复 3 次 WebFetch**: 哪怕改 prompt 也会拿到同样的截断结果,直接换 API 才是正解。
